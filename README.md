# 基金、股票观测对比平台

个人自用的多标的横向对比工具：把 A 股股票、ETF、场外基金放进同一个池子，拉齐口径比收益、比回撤、比估值、比持仓。

## 功能

- **归一化对比曲线**：任选 N 支股票/基金混合，区间起点归 0% 后叠加在一张图上；股票用前复权价、基金用分红再投口径的复权净值，天然消除分红失真
- **区间指标表**：区间收益率、年化、最大回撤、年化波动、夏普（无风险利率 2%）
- **估值分位**（股票）：PE-TTM / PB 及近 3 年历史分位（百度股市通数据）
- **同类排名**（基金）：近 3 月同类名次走势（天天基金数据）
- **持仓重叠**：多只基金最近季报前十大持仓重合度，重叠度 = 共同持仓取较小权重求和
- **观测列表**：东财联想搜索添加标的，SQLite 本地存储

## 数据更新

- 每周一至周五 18:10（Asia/Shanghai）自动同步全部观测标的
- 启动时若数据过期（>4 天）自动补抓；侧栏"立即刷新数据"可手动强制刷新
- 首次添加标的会后台抓全量历史（约几十秒），稍等即可对比

## 技术栈与数据源

| 数据 | 来源 |
|---|---|
| 股票/ETF 前复权日K | 腾讯行情（东财接口对程序化 TLS 指纹有拦截） |
| 场外基金净值 | 天天基金 pingzhongdata（单位净值 + 日增长率链乘 = 复权净值） |
| 基金持仓 / 同类排名 | 天天基金 F10（经 akshare） |
| 股票估值 PE/PB | 百度股市通（经 akshare，约近 3 年） |
| 标的搜索 | 东财 searchapi 联想 |

后端 Python FastAPI + SQLite，前端 Vite + React + ECharts，单容器部署。

## 部署（Docker）

```bash
docker compose up -d --build
# 浏览器访问 http://服务器IP:8000
```

数据（SQLite）持久化在 `./data/` 目录，升级镜像不丢数据。

## 本地开发

```bash
# 后端（终端 1）
cd backend && pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 前端（终端 2）
cd frontend && npm install && npm run dev
# 浏览器访问 http://localhost:5173（/api 已代理到 8000）
```
